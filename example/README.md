# WheelDatePicker example

Run `dotnative plugin run ios --project ..` or `dotnative plugin run android --project ..`.
Choose date opens the plugin; the page displays the selected date or cancellation.
Select `en-US`, `sr-Latn-RS`, or `ja-JP` to compare month-first, day-first,
and year-first ordering. The result is formatted using the selected locale.
